# UnitOfWorkState enumeration

Represents the lifecycle state of an [`IUnitOfWork`](./IUnitOfWork.md).

```csharp
public enum UnitOfWorkState
```

## Values

| name | value | description |
| --- | --- | --- |
| NotStarted | `0` | No transaction has been started yet. |
| Active | `1` | A transaction is in progress and can be committed or rolled back. |
| Committed | `2` | The last transaction was successfully committed and its resources were released. |
| RolledBack | `3` | The last transaction was successfully rolled back and its resources were released. |
| Failed | `4` | The commit threw an exception, or the rollback could not be confirmed. The final outcome of the transaction is indeterminate and its resources were released. |
| Disposed | `5` | The unit of work was disposed and can no longer be used. |

## Remarks

Typical transitions:

* NotStarted -&gt; Active via `Begin`/`BeginAsync`.
* Active -&gt; Committed via `Commit`/`CommitAsync`.
* Active -&gt; RolledBack via `Rollback`/`RollbackAsync`.
* Active -&gt; Failed when a commit throws or a rollback could not be confirmed.
* Committed, RolledBack and Failed -&gt; Active via a new `Begin`/`BeginAsync` (the unit of work can be reused).
* Any state -&gt; Disposed via `Dispose`/`DisposeAsync`. This state is terminal.
