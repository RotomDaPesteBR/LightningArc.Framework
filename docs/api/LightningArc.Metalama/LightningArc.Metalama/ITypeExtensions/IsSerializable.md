# ITypeExtensions.IsSerializable method

Determines if the return type is a type generally considered serializable or one that should be inspected by aspects.

```csharp
public static bool IsSerializable(this IType type, Type[]? notSerializableTypes = null)
```

| parameter | description |
| --- | --- |
| notSerializableTypes | A list of types to be recognized as non-serializable. Defaults to using the static property [`NotSerializableTypes`](./NotSerializableTypes.md). |
| type | The type to check. |

## Return Value

`true` if the type is not in the ignored types list; otherwise, `false`.

## Remarks

Checks if the type is not in the list of types injected by the framework (e.g., CancellationToken), as these should generally not be serialized or inspected for business logic.
