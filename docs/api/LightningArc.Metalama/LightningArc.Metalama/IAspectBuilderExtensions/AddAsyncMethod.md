# IAspectBuilderExtensions.AddAsyncMethod method

Introduces a new asynchronous method into the type, ensuring that the name ends in "Async" and the return type is wrapped in Task or ValueTask.

```csharp
public static IAspectBuilder<INamedType> AddAsyncMethod(this IAspectBuilder<INamedType> builder, 
    string templateName, string methodName, IType returnType, 
    Action<IParameterBuilderList>? parameters = null, object? args = null, 
    Action<IMethodBuilder>? methodBuilder = null, AsyncType asyncType = AsyncType.Task)
```

| parameter | description |
| --- | --- |
| templateName | The name of the code template that will be used for the method body. |
| methodName | The base name of the method (the part before "Async"). |
| returnType | The actual value type to be returned (TResult), before being wrapped in Task/ValueTask. |
| parameters | An optional Action to configure the method parameters. |
| args | An anonymous object that passes the values assigned to parameters that have the CompileTimeAttribute, for parameters of the same name in the introduced method. |
| methodBuilder | An optional Action for advanced method configurations. |
| asyncType | The type of asynchronous wrapper to be used: Task (default) or ValueTask. |
| builder | The aspect builder for the type (INamedType). |

## Return Value

The aspect builder to allow for call chaining.
