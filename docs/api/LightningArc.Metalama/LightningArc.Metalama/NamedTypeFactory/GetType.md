```csharp
public static INamedType GetType(string typeName)
```

| parameter | description |
| --- | --- |
| typeName | The full name of the type (including namespace and, for nested types, the '+' character). |

## Return Value

The INamedType that corresponds to the *typeName*.

## Exceptions

| exception | condition |
| --- | --- |
| InvalidOperationException | Thrown if the type is not found or if the TypeFactory is not available in the current context. |

## Remarks

For nested types, this means using '+', for example, to get `System.Environment.SpecialFolder`, use `System.Environment+SpecialFolder`.

For generic type definitions, this requires using '`', for example, to get `List<T>`, use ``System.Collections.Generic.List`1``.

Constructed generic types (e.g., `List<int>`) are not supported. For these, use IType[]).
