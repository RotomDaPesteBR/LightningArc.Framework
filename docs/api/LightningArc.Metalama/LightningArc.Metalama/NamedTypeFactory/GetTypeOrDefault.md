# NamedTypeFactory.GetTypeOrDefault method

Gets an INamedType based on its full name, as used in reflection, returning a default value if the type is not found.

```csharp
public static INamedType? GetTypeOrDefault(string typeName, INamedType? defaultType = null)
```

| parameter | description |
| --- | --- |
| typeName | The full name of the type (including namespace and, for nested types, the '+' character). |
| defaultType | The INamedType to be returned if the type is not found. The default is `null`. |

## Return Value

The INamedType that corresponds to the *typeName*, or *defaultType* if not found.

## Remarks

The naming rules for *typeName* are the same as those for [`GetType`](./GetType.md).

This overload returns *defaultType* instead of throwing an exception if the type is not found.
