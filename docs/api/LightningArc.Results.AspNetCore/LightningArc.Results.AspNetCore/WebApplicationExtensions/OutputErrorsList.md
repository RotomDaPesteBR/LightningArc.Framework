# WebApplicationExtensions.OutputErrorsList method

Generates and saves a markdown file containing the list of defined errors and their codes.

```csharp
public static void OutputErrorsList(this WebApplication app, string? filePath = null, 
    IErrorListFormatter? formatter = null)
```

| parameter | description |
| --- | --- |
| app | The web application instance. |
| filePath | The full path for the markdown file. Defaults to "ErrorsList.md" in the assembly's execution folder. |
| formatter | An optional custom formatter. If not provided, the default MarkdownErrorListFormatter will be used. |

## Remarks

The file is overwritten on each call. This method is useful in development environments to maintain an up-to-date record of the errors defined in the application.
