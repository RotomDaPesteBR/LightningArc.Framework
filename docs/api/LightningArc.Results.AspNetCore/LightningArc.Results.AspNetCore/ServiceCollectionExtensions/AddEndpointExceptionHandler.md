# ServiceCollectionExtensions.AddEndpointExceptionHandler method

Registers a global exception handler that converts unhandled exceptions into standardized library Error responses. This method also registers IServiceCollection) to enable standardized RFC 7807 responses.

```csharp
public static IServiceCollection AddEndpointExceptionHandler(this IServiceCollection services)
```

| parameter | description |
| --- | --- |
| services | The application's service collection. |

## Return Value

The same IServiceCollection instance for chaining.

## Remarks

To use this handler, remember to call `app.UseExceptionHandler()` or `app.UseEndpointExceptionHandler()` in your middleware pipeline.
