# CorsExtensions.UseCorsPolicies method

Adds predefined CORS policies to the application middleware.

* [`AllowAll`](../../LightningArc.CORS.AspNetCore.Policies/AllowAll.md).UseCors("AllowAll"): Adds a CORS policy that allows all origins, methods and headers.
