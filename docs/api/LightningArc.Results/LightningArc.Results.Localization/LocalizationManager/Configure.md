# LocalizationManager.Configure method

Configures the localization settings for messages. This method should be called once at application startup if custom localization is desired.

```csharp
public static void Configure(string cultureName, ResourceManager? errorResourceManager = null, 
    ResourceManager? successResourceManager = null)
```

| parameter | description |
| --- | --- |
| cultureName | The name of the culture to use (e.g., "en-US", "pt-BR"). |
| errorResourceManager | Optional. A custom ResourceManager to use for error message lookup. If not provided, the library's default error resource manager will be used. |
| successResourceManager | Optional. A custom ResourceManager to use for success message lookup. If not provided, the library's default success resource manager will be used. |
