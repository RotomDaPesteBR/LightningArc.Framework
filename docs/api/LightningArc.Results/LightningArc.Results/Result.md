# Result class

Represents the result of an operation that can be either a success or a failure. This is the base class for the Result pattern, used when an operation does not return a specific value upon success.

## Remarks

A [`Result`](./Result.md) is immutable, and its nature (success or failure) is defined at the time of creation. In case of failure, it encapsulates an [`Error`](./Result/Error.md) object that provides details about what happened.
