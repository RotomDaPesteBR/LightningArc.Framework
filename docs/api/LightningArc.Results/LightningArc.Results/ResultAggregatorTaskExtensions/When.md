# ResultAggregatorTaskExtensions.When method

## Remarks

Unlike [`Check`](../ResultAggregatorExtensions/Check.md)/[`CheckAsync`](../ResultAggregatorExtensions/CheckAsync.md), this method does not catch exceptions. If *condition* throws, the exception propagates normally.
