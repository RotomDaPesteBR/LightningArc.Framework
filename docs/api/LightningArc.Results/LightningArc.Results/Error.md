## Remarks

This base class is used in conjunction with the Result pattern to provide clear information about operation failures. Errors can be mapped to HTTP status codes in the application's presentation layer.

The error code is composed of a prefix (category) and a suffix (specific error). For example: 1001 (prefix 1 for "Application", suffix 01 for "Internal").
