## Remarks

This class is useful for aggregating multiple errors, such as those from multiple validation rules, into a single error object. It provides a structure similar to AggregateException.

[`Errors`](./AggregateError/Errors.md) contains the immediate child errors as they were combined (not flattened). [`FlattenedErrors`](./AggregateError/FlattenedErrors.md) and the inherited [`Details`](./Error/Details.md) provide the fully flattened view of all leaf errors.
