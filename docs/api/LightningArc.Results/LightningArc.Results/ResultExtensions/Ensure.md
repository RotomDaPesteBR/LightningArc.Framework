# ResultExtensions.Ensure&lt;TValue&gt; method (5 of 5)

Checks a condition and, if it is false, transforms the successful result into a failed result using the provided error. Does nothing if an existing failure is present. This is the synchronous **Ensure** operation for validation checks.

```csharp
public static Result<TValue> Ensure<TValue>(this Result<TValue> result, 
    Func<TValue, bool> predicate, Error error)
```

| parameter | description |
| --- | --- |
| TValue | The type of the value. |
| result | The input result. |
| predicate | The condition (function) to be checked against the success value. |
| error | The error to be returned if the condition is false. |

## Return Value

The original result (if successful and the condition is true), or a failed result.
