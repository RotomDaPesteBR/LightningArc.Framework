# ResultExtensions.Bind&lt;TOut&gt; method (1 of 2)

Binds a non-generic [`Result`](../Result.md) to a new [`Result`](../Result-1.md) by applying a function. This method is used to chain operations where the next step (defined by the *mapper*) also returns a [`Result`](../Result-1.md), allowing for propagation of success or failure.

```csharp
public static Result<TOut> Bind<TOut>(this Result result, Func<Result<TOut>> mapper)
```

| parameter | description |
| --- | --- |
| TOut | The type of the value contained in the output [`Result`](../Result-1.md). |
| result | The input non-generic [`Result`](../Result.md). |
| mapper | The function to apply if the input *result* is successful. This function takes no arguments and returns a [`Result`](../Result-1.md). |

## Return Value

A new [`Result`](../Result-1.md): If the input *result* is successful, the result of applying the *mapper* function. If the input *result* is a failure, the original error is propagated.
