# Error.GetErrorList method

Generates a list of all application errors, grouped by module.

```csharp
public static Dictionary<string, Dictionary<Type, ErrorInformation>> GetErrorList()
```

## Return Value

A dictionary where each key represents the name of an error module. The value is an inner dictionary where the key is the error type and the value is an [`ErrorInformation`](../../LightningArc.Results.Errors/ErrorInformation.md) instance with the error code and name.

## Remarks

The method scans all loaded assemblies for classes that inherit from [`ErrorModule`](../Error.ErrorModule.md) and their respective factory methods to list all available errors.
