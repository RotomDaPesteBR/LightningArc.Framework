# Error.Aggregate method

Combines zero or more errors into a single [`Error`](../Error.md).

```csharp
public static Error? Aggregate(IEnumerable<Error> errors)
```

| parameter | description |
| --- | --- |
| errors | The errors to combine. Individual `null` entries are ignored. |

## Return Value

`null` if *errors* is empty (or all entries are `null`); the single error unwrapped if exactly one non-null error is provided; otherwise an [`AggregateError`](../AggregateError.md) containing all provided errors, already flattened.

## Remarks

Unlike repeated use of [`operator +`](./op_Addition.md), this performs a single flatten pass over all inputs rather than re-flattening on every pairwise combination, making it the preferred entry point when aggregating more than two errors (e.g. in a validation loop) rather than accumulating via `+=`.
