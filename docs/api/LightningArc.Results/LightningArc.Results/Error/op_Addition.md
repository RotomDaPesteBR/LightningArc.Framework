# Error Addition operator

Combines two errors into an [`AggregateError`](../AggregateError.md). If both errors have the same code, the result maintains that code. If codes are different, a general aggregate code (99000) is used.

```csharp
public static Error operator +(Error? left, Error? right)
```

| parameter | description |
| --- | --- |
| left | The first error to combine, or `null` meaning no errors yet. |
| right | The second error to combine, or `null` meaning no errors yet. |

## Return Value

An [`AggregateError`](../AggregateError.md) containing both errors, or the non-null error if one is `null`.
