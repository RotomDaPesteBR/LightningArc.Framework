# ResultAggregatorExtensions.WhenAll method

Checks multiple asynchronous conditions concurrently and aggregates errors for any that evaluate to false.

```csharp
public static Task<ResultAggregator> WhenAll(this ResultAggregator aggregator, 
    IEnumerable<WhenCondition> conditions)
```

| parameter | description |
| --- | --- |
| aggregator | The aggregator to extend. |
| conditions | A collection of conditions paired with their respective errors. |

## Return Value

A task representing the asynchronous operation, with the current [`ResultAggregator`](../ResultAggregator.md) instance.

## Remarks

Unlike [`CheckAll`](./CheckAll.md), this method does not catch exceptions from individual conditions. If any condition throws or faults, the exception propagates via Task and aborts the batch. This is by design — the `When*` family carries no exception safety net.
