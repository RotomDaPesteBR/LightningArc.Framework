# ResultAggregatorExtensions.WhenAsync method

Checks an asynchronous condition and aggregates an error if the condition is false.

```csharp
public static Task<ResultAggregator> WhenAsync(this ResultAggregator aggregator, 
    Func<Task<bool>> condition, Error error)
```

| parameter | description |
| --- | --- |
| aggregator | The aggregator to extend. |
| condition | The asynchronous condition to check. |
| error | The error to aggregate if the condition is false. |

## Return Value

A task representing the asynchronous operation, with the current [`ResultAggregator`](../ResultAggregator.md) instance.

## Remarks

Unlike [`CheckAsync`](./CheckAsync.md), this method does not catch exceptions. If *condition* throws or faults, the exception propagates normally.
