## Remarks

This method cannot be used after an awaited step in the chain (e.g., after [`CheckAsync`](./CheckAsync.md) or [`CheckAll`](./CheckAll.md)), because `out` parameters are not allowed on `async` methods. The Task extension mirrors do not include this overload.
