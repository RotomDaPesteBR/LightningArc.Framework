# ResultAggregatorExtensions.CheckAll method (1 of 2)

Executes multiple asynchronous validation checks concurrently. All checks are started simultaneously and awaited together via Task. Each check may have an optional per-check callback invoked when that check resolves.

```csharp
public static Task<ResultAggregator> CheckAll(this ResultAggregator aggregator, 
    IEnumerable<AsyncCheck> checks)
```

| parameter | description |
| --- | --- |
| aggregator | The aggregator to extend. |
| checks | A collection of async checks, each with an optional callback. |

## Return Value

A task representing the asynchronous operation, with the current [`ResultAggregator`](../ResultAggregator.md) instance.

## Remarks

Each check's exceptions (both synchronous factory throws and task faults) are caught and converted to errors. No check failure or exception aborts the batch — all checks run to completion. Errors are aggregated in a single pass after all tasks complete. Per-check callbacks (if provided) fire as soon as each individual check resolves, with no ordering guarantee relative to other checks' callbacks. Callbacks run on arbitrary threads (no `ConfigureAwait(true)`). A throwing callback propagates normally and will fault its task, which Task will surface once awaited — this is intentional asymmetry: [`Action`](../AsyncCheck/Action.md) throwing is caught; [`OnComplete`](../AsyncCheck/OnComplete.md) throwing is not.
